# Skill: Scaffold Next.js App

## Purpose
Scaffolds a modern Next.js application with App Router, TypeScript, and Tailwind CSS.

## Trigger Phrases
- "scaffold nextjs app"
- "create frontend project"
- "new nextjs website"

## Workflow
1. **Initialize:** Run `create-next-app` or equivalent setup.
2. **Project Structure:** Organize folders into `src/app`, `src/components`, and `src/lib`.
3. **Configurations:** Setup `next.config.js`, `tailwind.config.ts`, and `tsconfig.json`.
4. **First Page:** Create a responsive landing page as `src/app/page.tsx`.
5. **Verification:** Run `npm run build` to verify build integrity.

## Directives
- Use `Ollama` for component boilerplate.
- Ensure all components are accessible (ARIA standards).
- Follow a "Mobile-First" CSS approach.
